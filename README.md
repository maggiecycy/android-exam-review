# Android 期末复习站

《金融系统应用开发与实践》期末复习用的静态网页。

按课件整理了第一到第五章的知识点与章节测试，并附带五套综合模拟题（单选、多选、判断、简答、代码补全、代码）。

## 怎么用

1. 打开本仓库中的 `index.html`（双击，或用浏览器打开该文件）。
2. 左侧选择章节：
   - **第一～五章**：先看「知识点」，再做「测试」
   - **综合模拟**：在「测试」页切换模拟一～模拟五
3. 做完后点「交卷看分」查看对错与参考答案。

不需要安装 Node、不需要构建；纯 HTML / CSS / JS，离线也能用。

## 内容范围

| 章节 | 内容 |
| --- | --- |
| 第一章 | 走进 Android（概念向，已压缩背景史细节） |
| 第二章 | 运行第一个 Android 程序（项目结构、模拟器/真机） |
| 第三章 | UI 设计基础（布局） |
| 第四章 | 常用 UI 组件与 Adapter |
| 第五章 | 页面跳转（Activity / Intent / Fragment） |
| 综合模拟 | 五套综合卷 |

## 本地预览（可选）

若浏览器对本地文件有限制，可在项目目录执行：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。
